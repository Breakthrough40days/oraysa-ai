# Oraysa AI architecture

## Current milestone
Responsive React/Vite learning interface with eight selectable modes, a conversation panel and a Vercel-compatible serverless chat endpoint. The API requires OPENAI_API_KEY and does **not** claim source verification. Source Library, history and explorer navigation are visual placeholders only.

## Planned milestones
1. Licensed Torah corpus retrieval with canonical source references, quotations and traceability (e.g. Sefaria API subject to terms and rate limits).
2. Source validation and citation links; separate retrieval evidence from model reasoning.
3. Supabase authentication, user-owned sessions, Hebrew-calendar learning journal and RLS.
4. Hebrew reader, morphology/gematria tools, compare-mefarshim view.
5. Interactive concept network and expanded learning modes.
6. Automated source-integrity tests, accessibility and production monitoring.

Do not deploy with an unrestricted public API key. Configure rate limiting, abuse prevention and cost controls before public launch.
